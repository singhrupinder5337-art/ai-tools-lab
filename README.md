# AI Tools Lab

A Python-based laboratory project demonstrating fundamental programming concepts through sorting algorithms and reusable utility functions.

## 1. Project Description

**AI Tools Lab** is a Python project created as part of a college laboratory assignment. It demonstrates basic algorithm implementation, function design, and code reusability.

The project includes:

- **Bubble Sort** — Sorts a list of numbers in ascending order.
- **`is_palindrome(s)`** — Checks whether a string is a palindrome.
- **`count_words(text)`** — Counts the number of words in a given text.
- **`celsius_to_fahrenheit(c)`** — Converts Celsius to Fahrenheit.
